# Проверка изменений проекта

Прочитай правила репозитория, описание задачи, diff и затронутые тесты. Проверь работу через обычную точку входа и сценарии ошибки, повторного запуска и старых данных. Сверь изменения правил расчёта с контрольными примерами.

- Для CRM проверь разрешения на сервере, область видимости данных, миграции и откат.
- Для каталога и бота проверь единицы товара, валюту, идемпотентность, сохранение данных, ошибки синхронизации и соответствие карточек источнику.
- Запусти целевые тесты. Отметь конкретные команды, результат и ограничения проверки.
- Для замечаний укажи серьёзность, файл и строку, условие проявления и последствия. Начни с дефектов, которые можно подтвердить по коду или результатам тестов.
